## Qué ha cambiado

# 🏞️ Destacados

- **Nuevos modelos de IA**: Compatibilidad con GPT-4.1, o4-mini, o3, Gemini 2.5 y Grok 3
- **Cadena de agentes**: Mezcla secuencial de agentes que permite que múltiples IA especializadas colaboren en tareas complejas
- **Mistral OCR para extracción de texto**: de documentos y gpt-4o-transcribe para transcripción de audio
- **Modelos de búsqueda web OpenAI**: para acceder a información en tiempo real
- **Entorno de código persistente**: Los archivos de Code Interpreter ahora pueden persistir entre sesiones de chat a pedido
- **Almacenamiento en la nube**: Integración de S3 y Azure Blob con URL de actualización automática para un manejo sólido de archivos
- **Herramientas de imagen OpenAI (GPT-Image-1)**: para generar y editar imágenes
- **Actualización de la interfaz de usuario**: UX, navegación, mejoras y optimizaciones de accesibilidad
- **Variables de fecha/hora especiales**: para mensajes y agentes que se utilizan dinámicamente
- **Sistema de recarga automática de saldo**: e integración mejorada de Redis para limitar la velocidad
