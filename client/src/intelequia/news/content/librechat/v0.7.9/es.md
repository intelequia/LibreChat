## Qué ha cambiado

### 🏞️ Destacados

**🤖 Marco de puntos finales optimizado** - Todos los puntos finales se han unificado bajo el marco de LibreChat Agents, simplificando la arquitectura y mejorando la coherencia entre los diferentes proveedores de IA. Esta importante refactorización consolida la base del código y permite una mejor paridad de funciones en todos los modelos compatibles.

**🔍 Búsqueda web** - Nueva funcionalidad de búsqueda web nativa con SearXNG/Serper, raspado Firecrawl y reclasificación semántica. La búsqueda web nativa del proveedor ahora también está disponible para OpenAI, Anthropic y Google.

**🧠 Memorias de usuario para contexto conversacional** - Sistema de memoria inteligente para el contexto de las conversaciones. Los usuarios pueden ver, editar y eliminar sus recuerdos a través de una interfaz dedicada, con opciones configurables

**🎏 Compatibilidad mejorada con el protocolo de contexto de modelo (MCP)** - Se agregó transporte HTTP Streamable, descubrimiento OAuth 2.0, credenciales proporcionadas por el usuario para servidores MCP desde la interfaz de usuario, marcador de posición dinámico y compatibilidad con Smithery, al tiempo que se mejora la compatibilidad del servidor

**🤖 Último soporte de LLM y parámetros avanzados** - Incluyendo los modelos omni-profesionales y de investigación profunda de OpenAI a través de la nueva API Responses, junto con Grok 4, Claude 4, Kimi de Moonshot AI y otros lanzamientos más recientes.

**📈 Sistema de comentarios de usuarios** - Un nuevo sistema de calificación de chat permite a los usuarios proporcionar comentarios sobre las respuestas de la IA

**🖼️ Manejo de archivos** - Soporte mejorado para varios formatos de archivos, incluidas imágenes HEIC, archivos H, cambio de tamaño de imágenes del lado del cliente para evitar errores de carga y soporte para avatares GIF con extensiones de archivos dinámicas.

**⚡Rendimiento y confiabilidad** - Optimizaciones que incluyen mejoras en el procesamiento de sincronización de MeiliSearch, nuevas consideraciones de rendimiento y manejo de errores extendido en toda la plataforma.

**🔐 Mejoras de seguridad** - Limitación de tasas adicionales, validaciones de permisos y correcciones para varios CVE

**⚙️ Configuración ampliada** - Actualización importante con nuevos proveedores de OCR (Azure/Vertex AI), personalización de títulos, **[y más.](https://www.librechat.ai/changelog)**
