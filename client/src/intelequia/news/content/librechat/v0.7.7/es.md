## Qué ha cambiado

## 🌄 Destacados

### 🌟 Nuevos modelos y capacidades de razonamiento
- Claude 3.7 con soporte de razonamiento y transmisión de pensamiento
- Soporte GPT-4.5
- o1-mini y o3-mini con llamadas de funciones estratégicas y `reasoning_effort` parámetro
- Razonamiento de agentes antrópicos para múltiples proveedores, incluido AWS Bedrock

### 🧠 Herramientas mejoradas y marco de agentes
- Capacidades ampliadas del agente con interfaz de usuario mejorada, gestión de artefactos y visualización de razonamiento
- Nuevas herramientas: datos meteorológicos de OpenWeather, análisis de vídeo de YouTube, generación de imágenes Flux
- Soporte para OAuth in Actions para conectarse sin problemas con servicios de terceros
- Agente xAI (Grok) compatible con una interfaz moderna

### 🔐 Seguridad y gestión de cuentas
- Autenticación de dos factores con códigos de respaldo y soporte QR
- Autenticación de Apple para un inicio de sesión optimizado
- Inicio de sesión SSO de GitHub Enterprise
- Sesiones de chat temporales para uso efímero

### 🧰 Funciones de desarrollo sólidas
- Edición y descarga de artefactos para mejorar el flujo de trabajo del código
- La API Code Interpreter ahora admite Rscript junto con los idiomas existentes

### 💻 Experiencia de usuario mejorada
- Mejoras en la calidad de vida de los mensajes para edición e interacción
- Configuración de conversación a través de parámetros de consulta de URL para compartir fácilmente
- Accesibilidad mejorada en toda la aplicación
- i18Next Soporte multilingüe con 18 idiomas
