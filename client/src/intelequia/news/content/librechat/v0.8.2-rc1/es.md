## Qué ha cambiado

## 🏞️ Destacados

* **👐 Importante revisión de accesibilidad** - Amplias mejoras para cumplir con los estándares WCAG
  * Mejor compatibilidad con lectores de pantalla, navegación con teclado, gestión de enfoque y relaciones de contraste
* **🏗️ Gestión dinámica del servidor MCP** - Agregue, configure y comparta servidores MCP directamente desde la interfaz de usuario con control de acceso
* **📌 Fija tus favoritos** - Fije agentes y modelos de uso frecuente en la barra lateral para un acceso rápido
* **🔐 Autenticación MCP mejorada** - Compatibilidad con OAuth heredado y otras correcciones de autenticación
* **⌛ Chat temporal predeterminado** - Establece el chat temporal como tu modo predeterminado en la configuración de usuario
* **🪨 Soporte de proxy de AWS Bedrock** - Configurar los ajustes de proxy para los puntos finales de AWS Bedrock
* **📦 Paquetes más recientes para Express.js v5 y MCP SDK**
