## Qué ha cambiado

## 🌄 Destacados

### 🤖 Agentes
- Presentamos el marco agente sin código de LibreChat
  - Cree asistentes de IA personalizados con proveedores compatibles, similares a la API de Asistentes y los GPT de ChatGPT ([aprender más](https://www.librechat.ai/docs/features/agents))
  - Admite Anthropic, OpenAI, AWS Bedrock, Azure OpenAI y puntos finales personalizados
- Mejorado con herramientas como Code Interpreter, DALL-E-3, Tavily Search y más
- Creación de herramientas dinámicas a través de especificaciones OpenAPI y servidores MCP

### 🎯 API de intérprete de código
- Ejecute código de forma segura en varios idiomas a través de un potente entorno sandbox ([aprender más](https://www.librechat.ai/docs/features/code_interpreter))
- Manejo y gestión de archivos sin problemas con organización segura basada en sesiones

### 🔌 Soporte MCP (herramientas)
- Presentamos la integración del protocolo de contexto modelo
  - el "USB-C de la IA" que estandariza cómo las aplicaciones proporcionan contexto a los LLM
- Obtenga más información sobre la integración de MCP y LibreChat en [modelocontextprotocol.io](https://modelcontextprotocol.io/clients#librechat)

### 🚀 Soporte para nuevos modelos
- Gemini 2.0 y el modo de pensamiento flash (, [más información](https://ai.google.dev/gemini-api/docs/thinking-mode))
- Nuevo modelo o1 "completo" y compatibilidad con o1-preview/mini streaming,
- Claude 3.5 Haiku
- Modelos de AWS Nova
