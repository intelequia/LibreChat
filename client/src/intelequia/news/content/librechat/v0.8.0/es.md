## 🏞️ Destacados

Principales características y mejoras desde [v0.7.9](https://www.librechat.ai/changelog/v0.7.9)

### 🔐 Sistema de permisos granulares
Revisión completa del sistema de permisos con control de acceso detallado, descubrimiento de grupos de ID de Entra y permisos de recursos basados en ACL (lista de control de acceso) con bits de permiso para agentes, mensajes, archivos y conversaciones.

### 🏪 Mercado de agentes con uso compartido avanzado
Ecosistema de mercado de agentes para descubrir y compartir agentes con categorización, sistema de promoción, diálogos de uso compartido avanzado con controles de acceso basados en roles y interfaz de usuario de selección de personas para búsqueda de usuarios/grupos/roles.

### 🤖 Actualizaciones de modelos
- **GPT-5** soporte con límites de tokens, tasas, capacidades de razonamiento y parámetros de detalle
- **Soneto de Claudio 4.5** Soporte, contexto actualizado y precios para los últimos modelos fronterizos de DeepSeek y Gemini

### ⚙️ Otros cambios notables
- Soporte de alojamiento de subdirectorios
- Mejoras de escala y compatibilidad de MCP
- Mejoras de rendimiento y confiabilidad en toda la aplicación
- Configuraciones adicionales para el gráfico Helm
- Integración de búsqueda web nativa para OpenRouter
- Opciones de configuración del grupo de conexiones MongoDB
- [Subir como soporte de texto](https://www.librechat.ai/docs/features/upload_as_text)
- Configuraciones adicionales para [Conexión OpenID](https://www.librechat.ai/docs/configuration/authentication/OAuth2-OIDC)
- [Integración de SharePoint](https://www.librechat.ai/docs/configuration/sharepoint) a través de la API de Microsoft Graph
