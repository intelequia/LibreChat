## Qué ha cambiado

# 🏞️ Destacados

- **Nuevos modelos de IA**: Compatibilidad con GPT-4.1, o4-mini, o3, Gemini 2.5 y Grok 3
- **Actualización de la interfaz de usuario**: UX, navegación, mejoras y optimizaciones de accesibilidad
- **[Cadena de agentes](https://www.librechat.ai/docs/features/agents#agent-chain)**: Mezcla secuencial de agentes que permite que múltiples IA especializadas colaboren en tareas complejas
- **[Mistral OCR para extracción de texto](https://www.librechat.ai/docs/features/ocr)**: de documentos y gpt-4o-transcribe para transcripción de audio
- **Modelos de búsqueda web OpenAI**: para acceder a información en tiempo real
- **Entorno de código persistente**: Los archivos de Code Interpreter ahora pueden persistir entre sesiones de chat a pedido
- **Almacenamiento en la nube**: [S3](https://www.librechat.ai/docs/configuration/cdn/s3) y [Mancha azur](https://www.librechat.ai/docs/configuration/cdn/azure) integración con URL de actualización automática para un manejo sólido de archivos
- **[Herramientas de imagen OpenAI (GPT-Image-1)](https://www.librechat.ai/docs/features/image_gen)**: para generar y editar imágenes
- **Variables de fecha/hora especiales**: para mensajes y agentes que se utilizan dinámicamente
- **[Sistema de recarga automática de saldo](https://www.librechat.ai/docs/configuration/token_usage#balance-configuration)**: e integración mejorada de Redis para limitar la velocidad
